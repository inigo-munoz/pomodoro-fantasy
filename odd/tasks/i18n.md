# i18n: English and Spanish (Spain), chosen in Settings

Branch `feat/i18n` (worktree `../Pomodoro Dragon review`, cut from `review/all` 583daaf). Delivery: ask-on-risk; merged into `review/all` for the user's review. Runner: `npx vitest run`, baseline 904 tests green.

## Specs

- **S1** (user, verbatim): "plantea la selección de idiomas y la traducción de la app completa." then "inglés y español de españa." — the whole app is available in English and in Spanish (Spain): every screen, button, message, toast, quest title, family tagline, food and furniture name, the instructions and the credits screen chrome. Creature names (Luna, Blaze, Coral…) stay the same in both. Authors' names, licence names and URLs in Credits are not translated.
- **S2** A language selector in Settings ("English" / "Español"), saved in the save's settings as `language: 'en' | 'es'`. On a save that has no language yet, the first value comes from the device (`navigator.language` starting with `es` → `es`, otherwise `en`). The store validation (`harden` in `src/store/store.js`) accepts only the offered languages; anything else falls back to the device default. No save version bump is needed (it is a settings field with a default), and every existing save keeps loading exactly as before apart from gaining `language`.
- **S3** Implementation (assumption, open to correction): no library. `src/i18n/en.js` and `src/i18n/es.js` dictionaries keyed by stable ids, and `t(key, params)` with `{name}` interpolation; plurals with `Intl.PluralRules`; weekday and month labels in the Record chart from `Intl.DateTimeFormat` in the chosen language. Changing the language re-renders the current screen; nothing else in the save changes.
- **S4** Tone: Spanish from Spain, `tú`, warm and simple for a nine-year-old; the same no-guilt rules apply in Spanish (no "perdido", "fallado", "caducado", "tarde", "fracaso", "racha", "aviso"…), and in English as today.
- **S5** Guards (tests): every key exists in both dictionaries with the same `{params}`; no screen renders English text when Spanish is chosen (render each screen in `es` and check no known English UI string remains); the no-guilt word lists are checked in both languages; quest titles exist for every quest id in both languages.
- **S6** Play Store listing text in both languages (short and full description) in `docs/play-listing.md`. Passive documentation.
